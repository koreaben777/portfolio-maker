# 보존된 실행·리뷰 기록

2026-10-11 분류: 이 디렉터리의 ledger, review, log, patch, hash, 승인 기록은 해당 시점의 이력이다. 과거 PASS/NEEDS_WORK를 현재 후보에 확대하거나 미완료 지시를 자동 실행하지 않는다.

현재 재개 기준과 모든 기록의 목록 위치는 [문서·기록 안내](../../../docs/DOCUMENT_INDEX.md)를 따른다. 기존 파일은 수정·이동·삭제하지 않았다. 이 안내 파일만 추가했다. 큰 데이터의 물리 정리·삭제와 worktree 정리는 이번 작업 범위가 아니다.
